Documentation, screenshots and release tooling. Nothing in the plugin's behaviour changes
between 1.0.0 and this release.

## What's new

- **`scripts/catalog.py`** — the plugin-catalog entry is generated, not hand-written: it
  reads `plugin.yaml` and the git remote, pins the 40-hex release commit, quotes the
  version, checks the banner is 2:1 and that every raw URL answers at that sha, and
  re-parses the YAML with both parsers in play.
- **`scripts/card.py`** — the catalogue card (podium + quality/cost Pareto), drawn in
  HTML/CSS and rasterised with the Chromium Hermes ships; `--all` renders the alternatives.
- **`scripts/shots.py`** — one run regenerates the README screenshots, the navigation GIF
  and the MP4 from the real desktop over CDP, clipped to the plugin's own pane.

## Fixes

- The capture run's criteria dialog was never closed (Escape is not wired in it), so the
  overlay covered the whole scenario; and the screencast captured zero frames because CDP
  screencast frames are events the client never read while it slept.

## Install / update

```
hermes plugins install model-leaderboard
```
